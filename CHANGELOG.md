# Changelog

Le versioni seguono [SemVer](https://semver.org/lang/it/) sul template
[`magiaslab/cruscotto-comune`](https://github.com/magiaslab/cruscotto-comune).

I fork vedono un avviso in **Riusa / fork** e **Attribuzioni** quando
`package.json` è indietro rispetto a `main`. I KPI AgID si aggiornano da soli;
questo file riguarda solo il **codice**.

Come mergiare: [`docs/aggiornamenti-upstream.md`](docs/aggiornamenti-upstream.md).

## 0.2.0 — 2026-08-27

- Next.js **16.3** e React **19.2** (Turbopack di default, Node ≥ 20.9).
- Questo repo è solo il **template da forkare** (dashboard). Il minisito di
  progetto vive a parte su [cruscottocomune.it](https://www.cruscottocomune.it).
- Avviso aggiornamenti upstream per i fork.
- Identità GitHub: `magiaslab/cruscotto-comune`.
